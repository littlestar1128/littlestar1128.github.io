# 交流电如何变成直流电：从整流桥到电容、电感滤波

交流电的方向不断变化，为什么经过几个二极管、电容和电感，就能给需要直流电的设备供电？

理解这个过程，可以先抓住两件事：**整流让方向一致，滤波让起伏变小。**

下面从一个简化电路出发，结合波形，看看这两件事分别是怎样完成的。

<!-- more -->

> **先明确安全边界：**本文是隔离低压交流的原理示例，不是可以直接接入市电的电源方案。整流桥和 CLC 网络本身不提供安全隔离，也不会自动把电压降到安全范围。**不要把图中的交流源直接替换为 220 V 市电。**
>
> 电容在断电后仍可能储存电荷；不要认为关机就能安全触碰。普通台式示波器的探头地夹通常连接保护地，不能随意夹到未隔离电路的整流负端 N，也不能通过断开示波器保护接地来“浮地”测量。本文不展开市电带电调试；相关风险参见 [Tektronix 的浮地测量安全说明](https://www.tek.com/en/documents/application-note/three-facets-floating-measurement-solutions)。

## 1 先看完整电路

![四二极管整流桥与 C1—L—C2 低压滤波示例电路](/image/posts/ac-to-dc/circuit.svg)

图中各部分的作用是：

| 元件或节点 | 含义与作用 |
| --- | --- |
| A、B | 交流源接入整流桥的两个端点 |
| D1～D4 | 四个二极管组成单相全波整流桥 |
| P、N | 整流桥的直流正端、负端 |
| C1 | 并联在桥输出两端的储能电容，先减小电压波动 |
| L | 串联在正供电路径中的电感，阻碍电流急剧变化 |
| C2 | 并联在负载两端，与 L 配合进一步滤波 |
| R | 代表用电设备的电阻负载 |
| Rs、Rw | 示例模型中的电源内阻和电感绕组电阻 |

整流桥在图中展开成上下两行，也可以画成常见的菱形。看图时，关键是辨认二极管的方向和节点连接关系。

这里采用的是 **C1—L—C2，也叫 CLC 或 π 型滤波**：两个电容接在两侧，电感串在中间。它是一种便于理解原理的示例接法，实际 AC/DC 电源会根据功率、体积和输出要求选择不同结构。[ADI 教材说明了这一滤波结构](https://wiki.analog.com/university/courses/electronics/text/chapter-6#rectifier_output_smoothing)。

## 2 整流桥把两个半周送往同一个方向

二极管可以近似理解为电流的“单向通道”。四个二极管组合后，交流源无论哪一端电位较高，负载都能得到相同极性的供电。

当 **A 比 B 电位高**时，电流经过：

```text
A → D1 → P → 负载及滤波网络 → N → D4 → B
```

当 **B 比 A 电位高**时，换另一条路径：

```text
B → D2 → P → 负载及滤波网络 → N → D3 → A
```

![正半周由 D1、D4 导通，负半周由 D2、D3 导通，两种情况下负载电流方向相同](/image/posts/ac-to-dc/diode-paths.svg)

两条路径的中间部分相同：电流都从 P 进入后级，再从 N 返回。于是，负载中的电流方向一致了。

只接电阻负载时，输出电压的形状可以近似看成正弦波的负半周被“翻到上面”。它仍然一鼓一鼓地起伏，因此叫**脉动直流**。

**直流不要求大小永远不变。** 在这个电路里，整流首先解决的是方向问题。[IIT Bombay 的二极管电路课件展示了桥式全波整流的两条路径](https://www.ee.iitb.ac.in/~sequel/ee101/mc_diodes_2.pdf)。

## 3 电容 C1 像小水库，峰值存能、低谷补能

如果只做整流，输入每次经过零点，输出也会降到零附近。很多设备需要更平稳的供电，这时就可以并联电容。

把 C1 想象成一个小水库：

- 输入接近峰值、足够高时，整流桥导通，电源给 C1 补充能量，同时向后级供电。
- 输入下降到不足以继续充电时，整流桥截止，C1 释放之前储存的能量，继续供电。
- 等到下一个峰值附近，电源再次给它补能。

这样一来，原本深深的低谷被抬高，输出电压只是在相邻的补电时刻之间缓慢下降。

所以，比起“削峰填谷”，**“峰值附近充电、峰间放电供能”更准确**。电容滤波后的电压往往靠近输入峰值，重点是减小低谷的下落幅度。

这里还有两个容易忽略的细节：

1. **有电容时，二极管不会在整个半周里一直导通。** 正、负半周决定哪一对管可能导通，实际还要看输入能否克服电容端电压和二极管压降。
2. **桥输出端和 C1 上端是同一个节点。** 接上 C1 后，这个节点的电压已经被保持，不能仍把它画成无滤波时的完整脉动波形。

桥式整流配电容时的充放电区间，可参见 [IIT Bombay 课件](https://www.ee.iitb.ac.in/~sequel/ee101/mc_diodes_2.pdf)。

真实整流桥在每条导通路径上都有**两只二极管串联**。忽略电源内阻等损耗时，电容充电峰值可粗略理解为 `Vpk − 2VF`，其中 `VF` 是单只二极管在相应电流下的正向压降。实际还会受电源阻抗和负载影响；不能把后文理想二极管模型的电压，直接当成实物输出。

## 4 电感 L 让电流别急变，C2 再缓冲电压波动

电容接上后，电压平稳了许多，但还有周期性的小起伏。这些残留的起伏叫**纹波**。

电感可以理解为给电流增加了“惯性”：

- 电流想快速增大时，电感产生阻碍变化的感应电压，同时把能量储存在磁场中。
- 电流想快速减小时，电感释放磁场能量，继续维持电流。

“来拒去留”说的就是这个特点：**电感反抗的是电流的变化，而不是把电流固定在某个数值。**

把 L 串在供电路径中，再在输出端并联 C2，两者就可以配合：L 减缓电流变化，C2 通过充放电缓冲负载端的电压波动。选值合适时，输出纹波会进一步减小。[ADI 教材给出了串联电感、并联电容的滤波电路](https://wiki.analog.com/university/courses/electronics/text/chapter-6#rectifier_output_smoothing)。

LC 的效果取决于电感、电容、负载和阻尼；它也可能出现谐振。因此，不能把“加了 LC”直接理解成“在任何条件下都更稳定”。

## 5 把电路和波形对照起来

![交流输入，以及仅整流、加电容、加 CLC 三种独立电路的稳态输出电压对比](/image/posts/ac-to-dc/waveforms.svg)

**后三条输出曲线来自三种电路分别接上相同负载后的结果，不能把它们当成完整 CLC 电路中的三个测量点。**

从上往下看：

1. **交流输入**：电压在正、负之间交替变化。
2. **仅整流**：输出不再变成负值，但仍有很大的起伏。
3. **加 C1**：峰间由电容供电，低谷明显抬高。
4. **加 C1、L、C2**：剩余起伏进一步减小，看起来接近直线。

最后一条曲线并没有完全变成直线，只是纹波相对于当前纵轴刻度很小。

### 这个例子用了什么参数？

| 项目 | 示例值 |
| --- | --- |
| 理想正弦交流源 | 50 Hz，峰值 10 V |
| 电源内阻 Rs | 2 Ω |
| 负载 R | 100 Ω |
| C1、C2 | 各 470 μF |
| 电感 L | 0.5 H |
| 电感绕组电阻 Rw | 5 Ω |
| 二极管 | 理想模型，忽略正向压降 |
| 观察状态 | 启动过程结束后的稳态 |

这里的 10 V 是**理想交流源的峰值**。对于正弦波，有效值等于峰值除以 √2，所以该电源有效值约为 7.07 V。波形图最上方画的是这一电源电压；电流流过 Rs 时会产生压降，因此桥的 A、B 端电压还受 Rs 影响。

按上述模型计算，三种电路的结果约为：

| 电路 | 平均输出电压 | 纹波峰峰值 |
| --- | ---: | ---: |
| 仅整流桥 + R | 6.24 V | 9.80 V |
| 整流桥 + C1 + R | 8.86 V | 1.35 V |
| 整流桥 + C1 + L + C2 + R | 8.48 V | 11.7 mV |

“纹波峰峰值”就是一个周期内最高电压与最低电压的差值。

CLC 示例的平均输出略低，与线圈电阻等模型参数有关；LC 并没有一个固定的降压比例。以上数值是简化模型的数值计算结果，**不是实物测量数据，也不是元件选型方案**。

计算中使用四阶 Runge–Kutta 方法，最终积分步长为 5 μs；从零初始状态运行到 2 s 后，再观察 60 ms 波形。脚本对相邻周期和减半步长后的结果做了检查，正文数值与模型输出一致。这些检查说明该数值计算已收敛，不代表模型包含了真实电路的全部非理想因素。

## 6 一个实用估算：电容越大，电压掉得越慢

对于**单相全波整流后的电容输入滤波**，当纹波较小、放电电流近似恒定时，可以用下面的式子粗略估算纹波：

```text
ΔVpp ≈ I / (2 × f × C)
```

其中，ΔVpp 是纹波峰峰值，I 是近似负载电流，f 是**原交流电的频率**，C 是滤波电容的容量，单位分别用 V、A、Hz 和 F。

全波整流在每个交流周期里有两次峰值。因此，50 Hz 输入对应 100 Hz 的补电节奏，相邻补电峰值约隔 10 ms。[Hacettepe 大学的整流与滤波讲义给出了这一频率关系及电容滤波计算](https://www.ee.hacettepe.edu.tr/~usezen/ele230/Rectifiers-6sp.pdf)。

例如，另取一个粗算条件：负载电流 0.1 A，输入 50 Hz，电容 1000 μF，即 0.001 F，则：

```text
ΔVpp ≈ 0.1 / (2 × 50 × 0.001) = 1 V
```

它表达的直觉很简单：**取电越多，电压掉得越快；电容越大，电压掉得越慢。**

这个近似式不能直接套到 CLC 输出端，也不要求精确复现上面的仿真值。电容增大还会改变充电峰值电流，实际选型需要结合电源和二极管的能力。[ADI 教材讨论了电容大小与充电峰值电流之间的取舍](https://wiki.analog.com/university/courses/electronics/text/chapter-6#rectifier_output_smoothing)。

## 7 波形平滑之后，还需要稳压吗？

**滤波减小起伏，稳压则要在输入或负载变化时，把输出维持在规定范围内。**

输入变高、负载变轻时，经过滤波的平均输出电压仍可能升高；输入变低、负载变重时，也可能下降。需要规定输出电压的电源，通常还要加入稳压电路或反馈控制。[ADI 教材将输出滤波和后续稳压分别说明](https://wiki.analog.com/university/courses/electronics/text/chapter-6#rectifier_output_smoothing)。

记住各元件的分工，就容易读懂这类电路：**二极管安排电流的方向，电容用电场储能缓冲电压，电感用磁场储能缓冲电流。**

## 8 从原理示例到实际电源，还缺哪些检查？

本文的 0.5 H、470 μF 等数值用于展示波形，并不是推荐的采购清单。要把原理变成实物，至少还要结合具体输入、负载和工作条件确认：

- **输入和隔离：**确认低压交流源的安全隔离、实际有效值和峰值，而不是只看标称电压。
- **整流桥：**检查反向耐压、工作电流、开机充电浪涌与散热；电容越大，不代表整流桥的压力越小。
- **电容：**检查极性、耐压、允许纹波电流和温升，考虑空载、输入升高及启动过程。
- **电感：**检查允许电流、饱和、绕组电阻与损耗，并结合负载检查 LC 的阻尼和瞬态响应。
- **输出要求：**先明确设备允许的电压范围、纹波和动态变化，再判断是否需要稳压与保护。

这是检查方向，不是完整的电源安规或产品设计流程。初学时优先使用仿真或有明确隔离与限流保护的低压教学设备，不把市电电路当作入门实验。
